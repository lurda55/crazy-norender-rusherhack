# Crazy NoRender

RusherHack plugin by **lurda55**.

Adds a Hotbar Item Names option to NoRender: hides the item name that pops up above the hotbar when you switch slot.

## Install

1. Download `crazy-norender-1.0.0.jar` from the [latest release](https://github.com/lurda55/crazy-norender-rusherhack/releases/latest).
2. Put it in `.minecraft/rusherhack/plugins/`.
3. Start Minecraft 1.21.11 with RusherHack (plugins must be enabled: `-Drusherhack.enablePlugins=true`).

## Build

```
./gradlew build
```

The jar is in `build/libs/`.
